# 免费模型资源

本原型实际使用 Poly Haven 的 **Mountainside** 山地扫描几何，去除纹理并转换为象牙白石膏材质。页面在加载后对几何进行艺术化重塑，收拢边缘、抬升山脊并重算朝上的法线；本地 GLB 保存去贴图的来源几何，山脊重塑逻辑保留在 HTML 内。

- 资产页面：https://polyhaven.com/a/mountainside
- 文件清单：https://api.polyhaven.com/files/mountainside
- 许可：CC0，https://polyhaven.com/license
- 本地文件：`models/qixia-white-mountain.glb`
- 为支持直接双击 HTML，`models/mountain-data.js` 保存同一 GLB 的 base64 数据。
- 模型是艺术化山地沙盘，不是栖霞山的测绘模型。景点位置为探索体验布局，不能用于实地导航。

可继续寻找免费模型的网站：Poly Haven（CC0）、Kenney（CC0）、Sketchfab（筛选可下载及 CC0 / CC BY，逐项查看许可）、像素风或低面数资源可看 Quaternius（逐包查看许可）。本轮仅采用以上 Poly Haven 模型，其余网站没有素材进入页面。

Three.js 及 OrbitControls、GLTFLoader：v0.128.0，MIT，https://github.com/mrdoob/three.js/blob/r128/LICENSE 。本地保存以支持离线演示。

## 拍照问精灵 · 精灵配音（2026-10-31 新增）

- **识图**：经 OpenAI 兼容中转 `api.openai-next.com` 调用 `gemini-2.5-flash-lite`，同时并发 `gemini-3-flash-preview-nothinking`，取先返回者（实测单次约 3.3–7 秒）。模型只判断照片属于该景点三个「看点」中的哪一个，并写一句角色回应；讲解内容本身是预先写好的脚本，不由模型临场编造。
- **配音**：`qwen3-tts-flash` 预生成，共 53 段，存于 `voices/*.m4a`（AAC 48kbps，约 4MB）。脚本见 `voices/scripts.js`，依据《栖霞山文化故事资料》撰写；乾隆、陆羽为数字角色演绎。
  - 音色：镜湖水灵 Serena、明僧绍 Kai、乾隆 Dylan（北京话）、陆羽 Ethan、石窟守护灵 Arthur、山石地质灵 Mochi、枫叶精灵 Bella、山灵 Li（南京话）、观光车播报 Neil。
  - 改文案或音色后运行 `node tools/gen-voices.mjs <条目名>` 重新生成，例如 `node tools/gen-voices.mjs lake-intro`。
- **密钥**：只存放在 `.env.local`，由本地服务 `server.mjs` 代为调用，页面中不含密钥。演示时运行 `node server.mjs`，打开 `http://localhost:8787`；同一 Wi-Fi 的手机可访问终端里打印的局域网地址。直接双击 HTML 也能打开，但拍照只走离线讲解。

## 真实地形与路网（2026-10-31 新增，替代 Poly Haven 山体）

- **高程**：AWS Terrain Tiles（Terrarium 编码，源自 SRTM 等公开数据），约 12 米网格。凤翔峰实测 273 米（官方 286 米）。显示时高度夸张 5 倍，1 个场景单位 = 240 米。
- **山界、道路、步道、停车场、水体、地名**：© OpenStreetMap contributors，ODbL 许可（https://www.openstreetmap.org/copyright）。对外展示时需保留此署名。
- 生成脚本：`python3 tools/build_qixia_data.py`，输出 `assets/qixia-data.js`（约 270KB）。需联网运行一次，之后页面离线可用。
- `models/mountain-data.js`、`qixia-white-mountain.glb` 与 `vendor/GLTFLoader.js` 页面已不再加载，可以保留备查，也可以删除。
- 八个景点、观光车站与南门/西门的位置：OSM 已有的直接采用（千佛岩、珍珠泉、凤翔峰、虎山等），其余依据《栖霞山导览图》与 12 个 OSM 地名做仿射配准得到，误差约 20–100 米。

## 观光车 · 出入口 · 停车（示意方案）

- 站点取自导览图上的「游览车停靠站」图标，吸附到真实道路。线路由程序沿 OSM 道路寻路：1 号线 西门→千佛岩→幽居桥→红叶谷→始皇临江处→天街（约 3.0 公里），2 号线 南门→饮马池→小营盘→天街（约 2.3 公里）。
- 时刻、车辆、车位、客流参数都在 `assets/transit-config.js`，拿到实地数据后改这个文件即可，不必改代码。
- **司机端实时定位**：先运行 `sh tools/make-cert.sh`（生成本机 HTTPS 证书，只需一次），再运行 `node server.mjs`。司机手机打开终端打印的 `https://局域网IP:8443/driver.html`，首次需「继续访问」，输入车牌后开始上报。游客页输入同一车牌，即可看到这辆车随真车移动，并标「实时」。
- 停车场车位按 OSM 面积估算（约 40 ㎡/位）。门口人数、余位、打车等候是按时段、周末、红叶季、天气计算的估算值。`transit-config.js` 的 `api.gates / api.parking` 预留了景区实测接口。
