# 栖霞山八景 · 人物故事海报提示词

这套提示词同时用于本地与云端的八景海报生成。使用时将「通用提示词」和对应景点的「专属提示词」拼接，并传入游客照片；有该景点的真实参考照片时一并传入。景点知识和文字应从知识库中检索并经审核后再填入。未提供景点实景照片时，画面只能作为艺术想象，不能称为实景复原。

## 一、通用提示词

```text
请根据游客上传的人物照片，创作一张原创的「栖霞山 · 山中行记」主题旅游纪念海报。

海报风格：创作一幅横向连续的山中旅行插画，主体是景点环境与游客的自然互动。画面有温暖的纸张肌理、自然的山林色彩与精细的手绘笔触。图像模型只绘制完整场景，不绘制任何文字区、空白卡片、边框、贴纸或拼贴。标题、故事与来源由系统放在这幅图片外的独立纸面区域。

人物处理：游客是故事中的旅行者，而不是居中占满画面的证件照。保留游客照片可辨认的面部特征、发型、年龄感、肤色及原有人数，不改变身份，不擅自美化、换脸或增加人物。优先保留游客原本衣着；如需延展衣着，仅自然补全照片看不到的部分。人物可在画面中行走、观景、驻足或阅读，以自然视线和姿态与环境产生联系。人物比例、透视、脚下接触关系、阴影、色温和景深要与场景统一，不能悬浮、穿模、出现多余肢体或像贴纸一样被贴上去。

若游客只上传半身照或证件照，先保留可见人物特征，可以采用半身、侧身但面部可见、坐姿等自然构图；对画面中不可见的身体、服装和姿态只能做合理的艺术补全，不得声称补全部分是原照片真实记录。不要让人物正面占据画面大部分。

景色处理：如果同时提供「景点参考图」，它是场景的视觉依据：尊重其中可辨认的真实山体、道路、文物、建筑和水体关系，不虚构不存在的建筑、碑文、佛像或地形。可以在构图、色彩和光线方面进行艺术化处理，不要把艺术加工标成真实拍摄。没有可靠实景参考时，使用与该景点主题相符的山水意境，不宣称是对真实地点的精确复原。

人物保护（八景均必须遵守）：保留输入照片中的原有人数、人物身份与可见面部特征。每个人的头顶、发型轮廓、额头、双眼、鼻子、嘴和下巴都必须完整可见，头部四周至少留出约一个头部宽度的安全空间；多人合影逐人保留，不互相挡脸，不让人物背对镜头。树叶、树枝、茶杯、手、石碑、建筑、山石、水花及其他前景物体不得遮住面部。人物脸部不能贴边或被画面边缘裁切。构图空间不足时扩大场景或调整站位，不能牺牲人物面部完整性。不要新增口罩、帽檐、围巾或饰品遮脸；原照已遮住的面部不能声称被真实还原。

故事结构：
1. 用连续的主画面讲清“游客来到了哪里、正在观察什么”，游客是场景中的自然主体，面部足够清晰可辨。
2. 景物细节仅在同一连续场景内自然呈现，位置以实景参考为准；不添加独立特写框、照片叠层或拼贴。
3. 所有标题、短引言、说明和来源都在图片之外由系统排版。画面内部不预留文字框，不生成白色方块、半透明面板或文字底板。
4. 色彩、氛围和季节与用户要求一致。红叶不是全年景象，不要把秋色说成实时状况。

视觉要求：生成图横向 3:2 或接近 3:2，完整保留人物头部与脸部。只生成无文字的完整插画，不生成文字、数字、标识、水印、二维码、贴纸或装饰边框。最终海报由系统在图片外添加标题、景点故事和来源；系统完整缩放图片，不裁切、不叠加覆盖层。即使用户要求拼贴或文字装饰，也必须保持人物面部完整可见，文字与装饰移到图片外。

游客的额外要求：{用户需求}
景点名称：{景点名称}
景点已核实资料：{知识库检索片段及来源}
可用景点参考图：{参考图及其说明；没有则写“无”}
```

## 二、各景点专属提示词

### 01 明镜湖 · 湖光铺开一页

```text
主题：明镜湖 / 彩虹明镜。海报标题建议「把湖光留在这一页」。

面部保护：湖岸人物的整张脸与头发轮廓完整呈现，曲桥、亭柱、岸边枝叶和倒影装饰不得跨过面部；自然侧身时仍保留清楚可辨的面部。不得添加说明框、拼贴或任何覆盖脸部的元素。

主画面：在有景点参考照片时，按参考照片中的湖面、曲桥与湖心亭构图。游客在岸边步道自然驻足，侧身看向湖面，画面主要留给水、树影与桥亭。光线与人物照片协调，水面倒影自然。没有参考照片时，只表现湖、树与亭桥组成的艺术想象，不声称实景位置。

场景内观察细节（不另做拼贴）：一处观察曲桥和湖心亭；一处观察树影与水面；一处以一片落叶或波纹作为旅途记忆。不要自行添加不能确认的石像或文字。

故事语气：从“停下来，看水面里倒映了什么”展开，温柔、安静，避免夸张抒情。可用短句：「湖中有亭，曲桥与岸相连。慢一点，看看水面收下了怎样的山色。」景物与季节以参考资料和用户选择为准。
```

### 02 明征君碑 · 把时间读慢一点

```text
主题：明征君碑。海报标题建议「一块碑，留住山中旧事」。

面部保护：游客与碑体、碑亭立柱错开站位，石碑及屋檐不得挡住人脸；保留头顶到下巴，观看碑刻时不采用完全背身。不得添加说明框、拼贴或任何覆盖脸部的元素。

主画面：以知识库提供的明征君碑照片为依据，表现碑亭、碑体与周边可见空间。游客站在开放参观区域安静阅读，人物适当缩小；保持碑体形制、方向与环境的可信关系。碑文不清楚时用石刻质感暗示，不要生成可辨认却不准确的文字。无参考图时，以“碑刻文化意境”表现，并标明艺术想象。

场景内观察细节（不另做拼贴）：碑石纹理、碑亭轮廓、游客凝视文字的动作。不得表现攀爬、触摸或破坏文物，也不要在石碑上创作虚构碑文。

故事语气：从“一个人与一座山的关系，由碑刻留给后人”展开。可用短句：「明征君碑与明僧绍的故事有关。站在碑前，读一读山中留下的文字。」具体年代及历史评价仅使用系统传入、已核实的资料。
```

### 03 乾隆行宫遗址 · 在遗址里寻找过去

```text
主题：乾隆行宫遗址。海报标题建议「旧址上的山风」。

面部保护：游客面部与遗址石构、标识和枝叶错开；站位必须让每个人的头部完整露出，不用复原建筑或装饰覆盖人物。不得添加说明框、拼贴或任何覆盖脸部的元素。

主画面：以知识库中的遗址实景照片为视觉依据，表现现存的遗址线索、石面、植被与山间步道。游客从参观路线旁观察遗址，作为较小的人物融入画面。保留遗址的现状，不要画成完整宫殿，也不要添加皇帝、宫女或未证实的复原建筑。无参考图时，只呈现带遗址意象的山林，不把虚构场景当成现状。

场景内观察细节（不另做拼贴）：可辨认的遗址标识、石材与植物、游客观看遗址时的视角；标识上的字如无法确认则不生成，文字解释由系统放在图片外。

故事语气：讲述“曾经有行宫，如今从遗址认识过去”。可用短句：「知识库记载，清代曾在栖霞山建行宫，后来毁于咸丰时期。今天，从留下的遗址线索认识它。」不补写未核实的宫殿结构、事件或对话。
```

### 04 茶文化点 · 在山中歇一盏茶

```text
主题：茶文化点。它是产品内的数字演绎入口，不自动等同于陆羽茶庄，也不代表陆羽曾在某个具体地点出现。海报标题建议「把山里的时间泡慢」。

面部保护：茶杯保持在胸口或桌面附近，手、茶杯、蒸汽均不遮住眼睛、鼻子或嘴；保留完整的脸与头发轮廓。不得添加说明框、拼贴或任何覆盖脸部的元素。

主画面：以山林、木桌、茶具与游客歇脚为核心，营造安静、自然的茶文化意境。游客在画面中品茶或观察茶具，茶具比例、手部姿态、光照和接触面自然。只有提供并确认某处真实茶庄照片时，才可以按该实景绘制，并在文案中使用其真实名称。

场景内观察细节（不另做拼贴）：茶叶、茶汤、山石与林间光线。不要表现陆羽本人，不要把虚构茶席画作真实历史现场，不添加未经证实的招牌或年代。

故事语气：从“走累了，留一点时间休息”出发。可用短句：「在山水之间歇一会儿，让一盏茶陪你慢慢看风景。」
```

### 05 千佛岩石窟 · 石头藏着慢时光

```text
主题：千佛岩石窟。海报标题建议「石头藏着慢时光」。

面部保护：让游客头部与岩壁龛像、山石和枝叶错开，不能为了突出石窟而让面部被遮挡；多人时逐个保留完整头部。不得添加说明框、拼贴或任何覆盖脸部的元素。
```

## 三、系统接入时的建议

- 每次提交用户照片、通用提示词和一个景点专属提示词；已核实景点参考图可作为额外图片输入，须保留图片来源与许可信息。
- 图像模型负责画面；标题、故事、资料来源必须由系统在图片外的独立区域排版，绝不覆盖图片。完整缩放生成图，不裁切任何边缘，不依赖人脸检测或模型为文字留空。不得重新加入已删除的「游客原照 / 景点参考照」独立拼贴区。
- 用户上传照片与模型生成画面应区分；若用户未到现场，应避免把 AI 想象描述成真实拍摄记录。
- 前述两处虚拟入口为“茶文化点”和“栖霞泉”；青锋剑石如果没有经确认的实景图，也应使用意境提示，不伪造实景。
- 输出前逐人检查头顶到下巴是否完整、是否被前景或装饰遮挡，再检查人物身份与人数、肢体与透视、虚构文物和资料一致性。
